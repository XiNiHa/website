소규모 스타트업 특성상 프론트엔드부터 백엔드, 모바일 앱, 인프라까지 다양한 분야의 개발 업무를 진행했으며,
후반에는 시니어 백엔드 개발자 퇴사로 생긴 공백을 메워 백엔드를 주도적으로 담당하는 한편
프론트엔드 신입 교육을 담당하고 업무를 분배하여 함께 진행하는 등 풀스택 개발 업무를 진행했습니다.

- **헬스케어 웹 제품 Vue/Nuxt 재작성**
  Angular 2 기반 MVP 웹앱을 Vue 2로, 의사용 PC 웹과 환자용 모바일 웹으로 구성된 B2B 제품을
  Nuxt 2로 재작성하며 SSR 최적화를 진행하고, Python/Falcon API 백엔드도 함께 유지보수했습니다.
- **Welcoach 모바일 앱 단독 개발 및 유지보수**
  건강보험공단 검진 데이터를 분석하여 맞춤 식품/건강기능식품 솔루션을 제공하는 Flutter 앱 Welcoach에
  단독 개발자로 참여하여 Play 스토어 출시까지 완료했고, 1,000회 이상의 다운로드를 기록했습니다.
  이후에도 네이티브 모듈 연동을 통한 간편 인증 기능 등 유지보수 작업을 지속했습니다.
- **웰코치샵 MSA GraphQL 백엔드 구축**
  웰코치샵 Shopify 쇼핑몰의 확장 기능을 위한 MSA 백엔드를 Kubernetes 위에서
  Schema Stitching 기반 단일 GraphQL API로 구축하고, 협력사 API 연동을 통해
  검진 상품 구매부터 리포트 제공까지의 전체 흐름을 구현했습니다.
- **Shopify 커스터마이징 및 웹 프론트엔드 개발**
  Shopify 쇼핑몰을 Liquid와 Svelte로 커스터마이징하고, 직접 개발한 Vite 기반 SSR 프레임워크인 Vilay로
  문진 및 리포트 페이지를 개발했으며, 신입 개발자 멘토링을 겸하였습니다.
